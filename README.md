# Tetris
Jeu Tetris fait en Python avec la librairie Pygame dans le cadre d'un projet en terminal

Pour jouer, téléchargez les deux fichiers _Tetris.py_ et _score.txt_, puis ouvrez et exécutez le fichier Python dans un éditeur de code.

Les blocs apparaîtront en haut de l’écran. Utilisez les touches flèches de gauche et de droite pour déplacer les blocs horizontalement, la touche flèches du haut pour les faire pivoter et la touche flèches du bas pour accélérer leur descente.
